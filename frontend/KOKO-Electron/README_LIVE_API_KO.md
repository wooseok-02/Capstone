# KOKO v0.4.0 — 프론트엔드/팀 API 연결 버전

기존 v0.3.3 Electron 펫·UI·알림 종 디자인을 유지하고 실제 팀 FastAPI 연결 기능을 보강한 **소스 코드**입니다. Windows .exe가 아니며, 실제 서비스 서버에서의 로그인/R2 성공을 검증했다는 뜻은 아닙니다.

## 가장 먼저 알아둘 점

- **공개 API 기본 주소**: `https://capstone.nsu-coco.online` (`/docs`는 백엔드 Swagger 문서)
- **실행 명령**: `npm run demo`는 백엔드 접속 없는 UI 시연, `npm start`는 실제 OAuth·백엔드 연동
- **기본 작업실 창**: 1440 × 900 CSS 픽셀, 화면 작업 영역보다 크면 자동 축소. 사용자 크기 변경 가능; 최소 800 × 600, 최대 1920 × 1080
- **소셜 로그인 필수**: 실제 업로드는 로그인 성공 후, 선택 폴더를 확인하고 앱의 별도 동의창에서 허용해야 시작됩니다.
- **SSH·DB 계정은 Electron에서 사용하지 않습니다.** 프론트 코드와 GitHub에 비밀키를 저장하지 마세요. 공유된 비밀번호는 즉시 변경해야 합니다.

## Windows 실행법

1. 기존 KOKO 인스턴스를 **시스템 트레이의 코코 메뉴에서 종료**합니다.
2. ZIP 압축을 풀어 `C:\KOKO_WORK` 같은 영문 경로에 `KOKO_WORK` 폴더를 둡니다.
3. 파일 탐색기에서 `package.json`이 있는 폴더로 들어가, 주소 표시줄에 `cmd` 입력 후 Enter.
4. `npm install` → `npm test` → `npm run demo` (오프라인 시연)
5. 실제 API 연동은 CMD에서 `npm start`로 다시 실행합니다. 코코 펫을 클릭한 후 Google/Naver/Kakao로 로그인합니다.
6. 로그인 화면에 서버 주소가 필요하면 `https://capstone.nsu-coco.online`을 입력하고 저장합니다. 동일한 주소가 기본값으로 들어 있습니다.
7. 작업실 → **파일 감지** → 폴더 선택 → 트리에서 제외·복구 → 최초 등록용 PC 이름 입력 → **저장 시작** → 실제 원본 업로드 확인창에서 허용.
8. 문서 등록 → Electron의 R2 서명 URL `PUT` → `upload-complete` → 서버 상태 조회 순서대로 진행됩니다. `ready`가 나오기 전에는 AI 완료로 표시하지 않습니다.

## UI 및 백엔드 기능

| 기능 | 구현 범위 |
| --- | --- |
| 펫 클릭 → 로그인/작업실 | 기존 OAuth 흐름 유지 |
| 폴더 선택·트리·X 제외·복구 | 실제 로컬 폴더 읽기, 서버에 제외 설정 저장, 등록 폴더 재선택 시 복원 |
| 최초 기기 등록 | 기기 이름 입력, 기기 ID 사용자별 로컬 저장 |
| 문서 업로드 | POST `/api/v1/documents` → **R2 직접 PUT (Bearer 없음)** → POST `/upload-complete` |
| 진행·결과 | 폴더 문서 목록에서 `uploaded/processing/ready/failed` 구분; 5초 간격 임시 조회 |
| 메인 실제 수치 | 실제 로그인 시 서버 폴더 목록 + 최근 폴더 문서 상태 반영 |
| 원본 다운로드 | `POST /api/v1/documents/{id}/download-url` 후 R2 직접 GET, 저장 위치 선택 (서버 응답 검증 필요) |
| 문서 파일명 검색 | 조회한 폴더 문서 기준 파일명 필터; **의미 검색 아님** |
| 알림 목록/근거 | 기존 UI 유지, 시연 모드만 예시 데이터 표시. 실제 알림 API의 **경로·요청·응답 명세를 받으면 연동 필요** |
| 파일 감시/자동 변경 업로드 | 이번 버전은 미구현. 초기 저장 버튼을 눌렀을 때의 업로드만 수행 |
| 삭제 API | 서버에서 영구 삭제 위험이 있으므로 자동 삭제·변경 감지 삭제는 **미연결** |

## 남은 팀 통합 검증

- 팀 서버의 Swagger `/docs`에서 최신 명세 검증 (이 제작 환경에서는 원격 서비스에 직접 접속할 수 없었습니다).
- Google/Naver/Kakao에서 **실제** OAuth → `/me` 성공 확인.
- R2 presigned URL의 헤더/접근 권한/CORS, 서버 `upload-complete` 동작 확인.
- 알림 API 명세 확보 후 알림 목록·읽음·연결 이유·원본 경로 연동.
- AI 검색어 임베딩 API 활성화 후 검색 UI 연동.
- 정태구 팀원과 800×600, 1440×900, 1920×1080, Windows 125% 배율에서 화면 확인.

## 보안

- 사용자 입력 폴더는 앱 내부에서만 탐색되며 동의 전 업로드하지 않습니다.
- `npm run demo`는 실제 서버로 문서/인증 정보를 보내지 않습니다.
- 비밀키/관리자 계정은 백엔드의 `.env` 또는 운영 비밀 저장소에서만 관리하세요.
- **공개 채팅 등에 전달된 서버 SSH 비밀번호와 DB 비밀번호는 변경하고 기존 비밀값을 폐기하세요.**
