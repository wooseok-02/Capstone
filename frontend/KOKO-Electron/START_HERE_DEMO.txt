KOKO v0.3.2 개발용 시연 모드 (로그인/백엔드 불필요)

1) ZIP을 완전히 압축 해제하고 KOKO_WORK 폴더를 영문 경로로 이동하세요.
   권장: C:\Users\사용자이름\KOKO_WORK
2) KOKO_WORK 내부에 renderer\pet.html, package.json이 있는지 확인하세요.
3) KOKO_WORK 폴더에서 RUN_DEMO.cmd 더블클릭.
   또는 주소창에 cmd 입력하고 아래 순서로 실행:
       npm install
       npm run demo
4) 오른쪽 아래 코코 고양이를 클릭하면 로그인 없이 작업실로 이동합니다.
5) 왼쪽 '파일 감지' 메뉴에서 폴더 트리, 제외·복구,
   저장 진행 시연, 결과 상세, 알림 내역·알림 상세를 체험하세요.

중요: UI 화면의 문서/추천/알림 데이터와 분석 수치는 샘플입니다.
실제 로컬 폴더 선택은 파일명 목록만 보여주고 서버로 업로드하지 않습니다.
개발용 시연 모드에서 실제 OAuth 로그인/업로드/AI 분석/API 호출을 하지 않습니다.

실제 팀 백엔드 테스트: 실행 중인 코코를 종료한 뒤 npm start 또는 RUN_KOKO.cmd.
실제 OAuth 로그인은 별도의 팀 서버 실행·설정이 필요합니다.

기존 실행 경로에 %/잘못 인코딩된 문자가 있으면 file:// URL 오류가 날 수 있으니
가능하면 C:\KOKO_WORK 처럼 영문/숫자만 사용하세요.
