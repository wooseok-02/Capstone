# KOKO v0.3.3 — 알림 종 아이콘 교체

첨부한 파란색 종 PNG를 코코 알림 아이콘으로 사용하도록 수정했습니다.

## 변경 위치
- 왼쪽 메뉴 **알림 기록**
- 왼쪽 아래 **알림은 조용히**
- 메인 대시보드 **새 알림** 카드
- **알림 내역** 화면의 안내 배너 및 알림 목록 아이콘
- **알림 상세** 화면의 문서 연결 알림 라벨

원본 이미지를 투명 PNG로 크기에 맞춰 정리한 `assets/koko-notification-bell.png`를 실제 UI에서 사용합니다. 원본 복사본도 `assets/koko-notification-bell-original.png`에 보관합니다. 기존 펫 이미지, 로고, OAuth/백엔드 동작은 변경하지 않았습니다.

## Windows 실행
1. 압축 해제 후 `KOKO_WORK` 폴더를 영문 경로(예: `C:\KOKO_WORK`)에 옮깁니다.
2. `RUN_DEMO.cmd` 더블클릭 또는 CMD에서 `npm install` -> `npm run demo`.
3. 실행 중인 기존 코코 인스턴스가 있다면 트레이에서 먼저 완전히 종료합니다.
4. 코코 펫 클릭 -> 작업실 -> **알림 기록** 화면에서 아이콘을 확인합니다.

실제 서버 모드: `npm start` (백엔드 OAuth 필요).
시연 모드에서는 업로드·AI 분석을 수행하지 않고 예시 알림 데이터를 표시합니다.
