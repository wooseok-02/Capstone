# KOKO UI 개발용 시연 모드 (v0.3.2)

## 실행

Windows: `RUN_DEMO.cmd` 또는 CMD에서 `npm install` → `npm run demo`.

기존 실서비스: `npm start` 또는 `RUN_KOKO.cmd` (OAuth 필수).

## 동작

- `--koko-ui-demo`를 명시한 **압축 해제된 개발용 앱**에 한해 시연 모드가 활성화됩니다. `app.isPackaged === true`인 패키징된 앱에서는 활성화되지 않습니다.
- 코코 고양이 클릭 → **메인 작업실 1440×900** (작은 모니터에서는 자동 축소). 로그인 화면 생략.
- 폴더 선택, 폴더 트리, 제외/복구, 로딩 애니메이션, 결과 상세, 샘플 알림 및 상세, 읽음 상태 표시 가능.
- UI 전체 상단에 **개발용 시연 모드** 표시, 저장/분석/알림은 샘플 값이라고 명시.
- 로컬 폴더 선택 시 파일 이름과 구조만 조회하며 내용을 열거나 서버에 전송하지 않습니다. 실제 폴더 결과는 AI 완료 수치로 표시하지 않습니다.
- 실제 로그인/토큰 복원/서버 업로드/API 상태 조회/AI 분석/알림 조회는 실행되지 않습니다. 백엔드가 없어도 됩니다.
- 저장 시연은 화면상의 애니메이션만 수행하며 **파일 내용은 전혀 전송하지 않습니다**.
- 사용자가 직접 선택한 로컬 폴더의 파일은 실제로 저장/분석되지 않으며, 시연용 결과 화면에는 이 점을 표시합니다.

## 실제 백엔드 연동으로 복귀

시연 앱을 완전히 종료하고 `npm start`를 실행하세요. 이때 기존 OAuth 인증 흐름이 유지됩니다. 

기존 프로젝트의 앱 데이터는 삭제하거나 로그아웃하지 않습니다. 다만 시연 중에는 계정 복원/토큰 갱신을 하지 않습니다.

## 검증

`npm test` — 기존 OAuth/문서 테스트와 추가된 시연 모드 라우팅 테스트를 실행합니다. 자동 테스트는 실제 Windows 화면 클릭까지 검증하지는 않습니다.
