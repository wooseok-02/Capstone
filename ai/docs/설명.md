## 상황별 명령어

`ai` 폴더에서 실행한다.

| 설명 | 명령단축어 |
|---|---|
| 새 `/upload` 요청·응답만 로컬에서 확인 | `python -m pytest -q test/test_upload_api.py` |
| 실제 파일 로딩·청킹·임베딩을 로컬에서 확인 | `make test-local` |
| 로컬 테스트 전체 실행 | `python -m pytest -q` |
| Modal 비교 테스트용 함수 배포 | `modal deploy modal_benchmark.py` |
| 로컬과 Modal의 임베딩 처리 비교 | `make test-compare` |
| 실제 `/upload` API를 임시 URL로 실행 | `modal serve modal_app.py` |
| 실제 API를 계속 사용할 URL로 배포 | `modal deploy modal_app.py` |
| Modal 처리 실패 로그 확인 | `modal app logs capstone-ai` |


2. 외부 서비스 결정 기준

| 기준 | Modal | RunPod Serverless Flex | Hugging Face Inference Endpoints |
|---|---|---|---|
| **요청 없을 때** | 기본적으로 0개까지 축소. 종료 전 유휴 자원은 과금 | 0개까지 축소. 종료 전 대기 시간도 과금 | Scale-to-zero 설정 가능. 축소될 때까지 인스턴스 과금 |
| **유휴 대기 기본값** | 최대 60초, 조정 가능 | 5초, 조정 가능 | 기본 1시간 후 축소, 설정 가능 |
| **요청 처리 비용** | 사용·예약한 CPU·메모리·GPU 자원을 시간 기준으로 계산 | 워커 시작·처리·종료 전 대기를 초 단위로 계산 | 초기화·실행 중인 인스턴스를 분 단위로 계산 |
| **콜드 스타트** | 컨테이너 시작·라이브러리 초기화·모델 로딩 필요 | 워커 시작·모델 로딩 필요. FlashBoot·캐시로 완화 가능 | 모델에 따라 수분 걸릴 수 있다고 공식 안내 |
| **우리 코드 배포** | Python 함수와 실행 환경을 정의해 연결 | 컨테이너와 처리 핸들러 구성 | 전체 파이프라인은 커스텀 컨테이너 등 별도 구성 필요 |
