# 문서 로딩 작업 정리

작성일: 2026-11-18

## 1. 이번에 할 일

파일에서 본문과 메타데이터를 읽어 LangChain의 `Document`로 만드는 부분만 다룬다. 
청킹·임베딩·벡터 DB 저장은 이후 작업이다.

[내 PC에서 구현·실행 확인 → pytest로 기본 동작 검증 → AI 서버 배포 → 백엔드에서 API 연동]

## 2. 로컬 파일을 읽는 케이스

| 실행 위치 | 처리 방식 | 필요한 준비 |
|---|---|---|
| 사용자 PC | PC에 설치한 Unstructured로 직접 읽는다. | 라이브러리와 파일 형식별 추가 프로그램 설치 |
| 우리 서버 | 원본 파일을 업로드하고, 서버에 설치한 Unstructured로 읽는다. | 서버 실행 환경·파일 업로드 연결 |
| AI 서버 | 원본 파일을 업로드하고, AI 서버에 설치한 Unstructured로 읽는다. | AI 서버 실행 환경·파일 업로드 연결 |
| Unstructured 업체 서버 | 업체 API로 원본 파일을 보내고 처리 결과를 받는다. | API 키·API 호출 연결·이용 요금 확인 |

- 사용자 PC: 지금 테스트할 때는 내 컴퓨터, 배포 후에는 앱을 설치한 사용자의 컴퓨터.
- 우리 서버: AWS 같은 환경에 배포해 팀이 운영하는 서버.
- AI 서버: 임베딩 모델 등을 실행하는 서버. 우리 서버와 분리할지는 아직 미정.
- ‘라이브러리 직접 실행’은 코드를 실행하는 컴퓨터에서 처리한다는 뜻이다. 사용자 PC와 우리 서버 모두 가능하다.
- 문서 로딩 위치와 임베딩 위치는 별개다. 로딩에 반드시 GPU가 필요한 것은 아니다.

## 3. 첫 구현 방향과 미정 사항

| 항목 | 현재 정리 |
|---|---|
| 첫 로더 후보 | 여러 파일 형식을 처리하는 `UnstructuredLoader` |
| 구현 순서 | 사용자 PC →  AI 서버 → Unstructured 업체 API |
| 서비스 지원 확장자 | 아직 확정하지 않음. 로더 지원 목록과 우리 서비스 지원 범위는 별도 |
| 최종 실행 위치 | 각 환경에서 구현해본 뒤 결정 |

## 4. 무엇부터 해볼지

1. 내 개발 환경에 Unstructured 로컬 실행 환경을 설치한다.
2. 정상적인 샘플 파일 하나를 로드한다. 첫 파일은 `.md` 형식
3. 반환된 `Document`의 본문과 메타데이터를 출력해 확인한다.
4. 다른 형식이 필요해지면 샘플을 추가해 읽어본다.

처음부터 모든 형식과 실행 위치를 구현하거나 비교할 필요는 없다. 
직접 읽는 코드는 나중에 서버에서 실행해 비교할 수 있다.

## 5. Unstructured 오픈소스 공식 지원 형식

| 종류 | 확장자 |
|---|---|
| 텍스트·Markdown | `.txt`, `.md` |
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| PowerPoint | `.ppt`, `.pptx` |
| Excel·표 데이터 | `.xls`, `.xlsx`, `.csv`, `.tsv` |
| 웹 문서 | `.html`, `.xml` |
| 기타 문서 | `.odt`, `.rtf`, `.rst`, `.org`, `.epub` |
| 이메일 관련 | `.eml`, `.msg`, `.p7s` |
| 이미지 | `.bmp`, `.heic`, `.jpeg`, `.png`, `.tif`, `.tiff` |

HWP·HWPX는 확인한 공식 오픈소스 지원 목록에 없다. 형식별 추가 설치가 필요할 수 있으며, 지원 목록만으로 실제 문서의 추출 품질까지 확인된 것은 아니다.

## 6. 시간·비용에 대해 현재 아는 것

| 구분 | 시간 | 비용 |
|---|---|---|
| 사용자 PC에서 직접 로딩 | PC 사양과 문서 종류·처리 방식에 영향받음 | 별도 로딩 API 요금 없이 PC 자원 사용 |
| 우리 서버·AI 서버에서 직접 로딩 | 원본 업로드 시간 + 서버 처리·대기 시간 | 서버 자원 사용에 따른 비용 |
| 업체 API | 업로드·네트워크·업체 처리 시간 | 업체 요금제에 따른 비용 |

같은 파일·같은 로더 설정으로 사용자 PC와 외부 서버를 직접 비교한 신뢰할 만한 자료는 이번 조사에서 찾지 못했다. 실제 속도 차이가 필요하면 같은 샘플과 설정으로 측정한다. 현 단계에서 특정 위치가 몇 배 빠르다고 결론 내리지 않는다.

## 7. 외부 서비스는 이후 별도 연결

현재 구현 대상은 로컬 파일 로딩이다. 
노션·구글 드라이브는 변경 알림과 API로 최신 내용을 가져오는 부분이 추가된다.
가져온 내용을 `Document`로 만든 뒤 후속 처리에 연결하는 흐름은 공통이다.
